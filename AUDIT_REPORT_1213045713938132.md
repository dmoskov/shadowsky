## Cleanup Pattern Analysis

### Pattern: Ref-based Cleanup
All persistent timers use the ref pattern:
```typescript
const timeoutRef = useRef<ReturnType<typeof setTimeout> | null>(null);

// Usage
timeoutRef.current = setTimeout(() => { ... }, delay);

// Cleanup in useEffect return
return () => {
  if (timeoutRef.current) {
    clearTimeout(timeoutRef.current);
    timeoutRef.current = null;
  }
};
```

### Pattern: Scoped Cleanup
Short-lived timers in async functions are cleaned up immediately after use or in the same scope's cleanup.
