## Technical Details

### Why This Fix Prevents Memory Leaks

1. **Event Listener Accumulation**: Without cleanup, each time the component mounts/unmounts or the video source changes, new event listeners are registered but old ones remain attached to the HLS instance.

2. **Reference Chain**: Event listeners maintain references to React state setters and other closure variables, preventing garbage collection.

3. **HLS.js Behavior**: While `hls.destroy()` does clean up internal resources, explicitly calling `.off()` ensures event listeners are removed before destruction, following HLS.js best practices.
