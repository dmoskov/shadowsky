# Dependencies Quick Reference

## Common Commands

```bash
# Check for outdated dependencies
npm run deps:check

# Check for security vulnerabilities (production only)
npm run deps:audit

# Check for security vulnerabilities (all dependencies)
npm run deps:audit:all

# Update to latest compatible versions (within semver range)
npm run deps:update:safe

# View dependency tree
npm ls --depth=0

# Check bundle size impact
npm run analyze
```

## Adding New Dependencies

Before adding a new dependency:

1. **Evaluate necessity**: Can this be done with existing dependencies or vanilla JS?
2. **Check package health**: Use https://snyk.io/advisor/ or https://npm.io/
3. **Check bundle size**: Use https://bundlephobia.com/
4. **Review alternatives**: Search for lighter/better-maintained options

```bash
# Install and save
npm install <package-name>

# Install dev dependency
npm install --save-dev <package-name>

# Check bundle impact
npm run analyze
```

## Automated Updates

This project uses Dependabot (runs weekly on Mondays):

- **Grouped updates**: Related packages updated together
- **Security patches**: Applied automatically
- **Major versions**: Require manual review

Updates are grouped by category:

- AT Protocol packages (`@atproto/*`)
- React ecosystem
- Testing tools
- Linting/formatting
- Build tools
- AWS/Amplify
- Media processing

## Update Policy

### Weekly Updates (Automated via Dependabot)

- Minor and patch version updates
- Grouped by package category
- Reviewed and merged within 1-2 days

### Manual Review Required

- Major version updates
- Breaking changes
- Critical production dependencies

### Security Updates

- **Critical (CVSS ≥ 7.0)**: Apply within 24 hours
- **Moderate (CVSS 4.0-6.9)**: Apply in next weekly cycle
- **Low (CVSS < 4.0)**: Apply in next monthly review

## Troubleshooting

### Package lock conflicts

```bash
rm -rf node_modules package-lock.json
npm install
```

### Outdated cache

```bash
npm cache clean --force
npm install
```

### Audit fixes

```bash
# Try automatic fixes first
npm audit fix

# For breaking changes
npm audit fix --force  # ⚠️ May cause breaking changes
```
